# 训练前决策与约束

基准为公开 `39f23b5`。2026-11-23 任务重新授权本地训练，但本轮不 push、不部署、不上传权重。远端已核对仍是该提交，Issues #19–24 已读取并保留本地快照索引。旧“禁止微调”限制由用户本轮任务撤销。

依赖：旧实验 score/cache/candidate/source → 独立评分审计；campusSnapshot/answerCampus → 时间范围、关系完整性与接口；generation/notice → 模型原文整理和来源核验；generation/model 与新本地 MLX worker → 显式模型选择、回滚、完整身份缓存。保留 web 与 evaluation 金标，训练不修改原 GGUF、旧模型环境或旧实验。

机器：M1 Pro，8 CPU 核、14 GPU 核、32 GB 统一内存，Metal 可用。初始磁盘 2.5 GiB；安装隔离 MLX 0.32.4 / MLX-LM 0.32.2 和官方 BF16 0.5B 后余约 1 GiB。官方可训练权重固定 7ae557604adf67be50417f59c2c2f167def9a775，SHA 为 fdf756fa7fcbe7404d5c60e26bff1a0c8b8aa1f72ced49e7dd0210fe288fb7fe。未用推理 GGUF 作为训练 checkpoint。

数据先以每集合 200 世界的小集运行自动引用/日期/身份检查。发现重复 QA 输入后修为不同字段问题；发现导入日期不在抽取输入后补充原文明示的本地导入元数据；含糊/传闻草稿提取应 pending 而非确定条款。重新冻结后再训练。有限模板碰撞仍如实报告。

首版 20,000 世界的事实状态指纹只有 18,506（移除课程和班级名称），不能把世界 ID 数冒充新增语义覆盖。因此正式数据量上调为训练 24,000 世界/120,000 样本、验证 1,200 世界/6,000 样本、测试 2,400 世界/12,000 样本。四类配额同比例为 36k/30k/42k/12k，不省略任何任务；训练/验证/测试的实体、文体族和世界隔离，报告事实指纹数及近重复。支持 --train-worlds 60000 生成 300k 扩容，不冒称扩容实验已跑。

试训使用固定 1k 开发子集，截断为零，最长 1536 tokens，LoRA 只动最后八层 q/v，rank8、scale2（等效 alpha16）、dropout0、AdamW 1e-4，batch2，500 次更新一轮。参数为本机可用工具链闭环初值，并非已调优正式配置。记录全部 mask/EOS/实际 token、内存、耗时、保存/重载与验证输出。独立 test 不参与选 checkpoint。试训最后 checkpoint 仅做工具验证，不称正式模型。

正式 100k+ 训练及 1k/10k/50k/100k 收益曲线在数据审计、500 条真人语义抽查、验证指标与资源预算通过后才能启动。人工未完成时保留 blocker 和所有可推进产物；不伪造 reviewer、不以自动检查充当人工审核，不自行租用云算力。loss 下降不等于系统改善。
