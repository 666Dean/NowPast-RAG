# NowPast Qwen 领域适配试验模型

基于 Qwen2.5-0.5B-Instruct 的 LoRA 领域适配试验，不是从零训练的基础模型，也不是 GNP 神经网络。官方 base 许可为 Apache-2.0，固定 revision 和文件散列见 base-source.json 及运行 manifest，交付保留原 LICENSE。合成训练材料不是实际教师或学校标注。

当前只授权本地开发。试训 adapter 在 training/runs/smoke-1k；它使用 1k 开发子集，不是十万条正式模型。是否已完成、实际更新数、token、内存、保存摘要和配对输出必须看 training-manifest.json / task-metrics.json，不能凭脚本存在或 loss 下降认定可用。早期错误标签试验在 pilot-invalid-future，不可部署或计为成功成果。

适用研究：完整原文抽取、关系授权、当前/历史分离、字段问答、冲突与缺证。当前训练来自有限生成文体，实体归一后模板重复很高；独立自然教师语言效果未知。自由输出可能不完整、误引用或误判关系。服务保留原文引用、日期、身份、授权与完整性校验，不通过即 pending/失败，不读金标改写答案。

正式训练状态：等待组长安排至少 500 条真人语义审查，并复核数据系统性修订。120k+ 正式训练、10k/50k/100k 训练规模曲线、固定微调模型跨检索系统的独立测试、合并/量化等未运行阶段不可宣传为完成。已有 230 题是诊断数据，不能复用作盲测。

MLX 原始 base、adapter 可显式选择；原 GGUF 始终保留。smoke adapter 只允许 `NOWPAST_ALLOW_SMOKE=1` 开发接入。若不指定 adapter，finetuned 模式应失败，不自动回退并冒称微调模型。回滚为移除新环境变量、使用旧默认推理服务。

合并与再量化不是本轮可默认完成的步骤：当前磁盘余量约 1 GiB，完整 BF16 合并副本还需约 988 MB 加临时/安全空间。保留 base+adapter 即可本地推理，合并、GGUF 或 ONNX 导出只有实际执行并复测后才能登记。

不依赖第三方托管模型服务。离线验证必须在预装依赖和权重后重启进程并禁用外联，保留实际原文、查询、引用与失败输出。进程级外联封锁可作为可重放证据，但不冒称用户整台电脑断网。现有本地服务不等于公开网页部署或比赛正式提交。
