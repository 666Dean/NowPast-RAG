# 条款数据与引用

执行负责人为 **组员 AI**。任务跟踪见 [Issue #2 · 条款数据与引用](https://github.com/666Dean/NowPast-RAG/issues/2)。

## 现有实现

已有固定来源链接、演示库与基础校验。 本目录的主要文件为 data.mjs、schema.mjs。

## 职责与依赖

维护原创课程资料、原子条款字段与独立研究引用表。

上游为 research。下游向 temporal、retrieval、qa 提供 seed、references、validateDocument；refs 只指向已核查的研究来源。

## 第一项工作

用一次新的课程补充通知验证资料录入。记录适用组、公布/生效/导入日期，并覆盖一条旧规则的两个并行后继；再列出元数据缺失时的预期行为。

## 完成条件

新条款的 value 可在原文中逐字找到；历史日和另一组不会提前适用更新；提供资料许可或自编来源。

提交时写明所改文件、用于验证的查询及实际结果。涉及其他模块的输入输出变更时，在 PR 中写出影响的调用方。[协作总表](../CONTRIBUTING.md)
