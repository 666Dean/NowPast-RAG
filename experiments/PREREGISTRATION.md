# 预登记实验（运行前固定）

配置见 config.json。先运行 generate.mjs 生成并写入 freeze.json（每个种子的压缩数据 SHA256 和配置 SHA256），然后运行检索和生成。开发世界 0–9，测试世界 10–59，各种子每世界 200 问，测试每种子 10,000 问。课程、教学班、事件、原文标题、模板词组均按世界划分；开发/测试提问词组分别登记。跨种子独立世界 ID。重复同一事件的问法属于相关样本，不能当作独立受试者；置信区间按世界聚类重采样。

金标在事件构造时登记检查点：原始安排、变更、分叉、澄清、公布前后、导入前后。生成器不导入 answer、snapshot 或检索代码。课次日期与查询知识时点分开。校务 `asOf` 指本地已知资料：公布和导入均不得晚于该日，生效须不晚于所问课次（作业则不晚于知识时点）；不把晚导入资料投影到过去已知集合。原 GNP 的旧接口和冻结金标保持不动。

共同输入为原文、标题、公布/生效/导入日、班级、课程、课次或作业和字段。人工结构化条件还提供可核查关系，所有方法都可见相同资料及元数据；向量/BM25 不执行图运算。平面每原文短通知一个块，不按金标切块；固定 top-k=5，固定上下文 6,000 字符，超过预算从尾部停止，绝不按金标数量改变 k。完整语料检索后按公布/导入日屏蔽不可见项。向量模型使用固定 BGE 中文 v1.5 ONNX 量化版本、CLS 池化、L2 归一化、点积检索。向量查询加官方中文检索指令。BM25 使用统一中文二元字串/拉丁词分词，k1=1.2、b=0.75。Latest 是独立规则排序基线（同身份每字段最新公布），不是经典 RAG。

NowPast 使用实际校务 snapshot 和显式替代关系，再以词法相关性在当前/历史通道内排序，固定同一 k。no-history 只去掉历史候选；no-graph 保留身份过滤，去掉生效与替代图处理。原文自动整理条件仅从原文恢复字段与关系，不读取人工 supersedes 或金标；单独报告。

至少 200 个跨种子/场景分层测试问题固定用于所有方法的真实 Qwen2.5-0.5B Q4_K_M 生成。所有方法使用同一 system prompt、JSON 结构、温度 0、seed 42、max_tokens。模型根据原始证据选择回答所需的当前证据 ID 与旧通知 ID，值从所选原文条款逐字回填并验证；不会把 NowPast 的规则答案作为模型答案。相同输入缓存允许跨方法复用，必须披露真实推理次数、缓存次数、耗时和实际 token。模型失败计为失败，不用金标补答。

检索阶段单列证据召回、当前证据精确率、引用与旧链接；生成阶段单列字段集合 exact/F1、引用精确率、旧链接、时间错误、跨范围误用、冲突保留、缺证弃答。报告总体/场景/消融/规模变化、逐题结果、代表性错例、索引成本。结构化上限不冒充原文模型全自动端到端结果。合成数据实验不外推到真实学校效果。
