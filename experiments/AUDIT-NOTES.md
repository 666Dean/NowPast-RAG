# 冻结与分析变更记录

1. 首版开发集审计发现“多次替代”检查点与后续并行通知同日公布，按日粒度已无法区分两阶段。只检查开发世界后，将并行公布延后一日、澄清再后一日；修正数据脚本并重新冻结。测试集在这次修正前未读分数，未据测试题调参。修正后开发世界 2,000 问逐题核验，当前证据与独立登记检查点零差异。
2. 首轮全库检索输出后，看到向量检索显著低于 BM25；考虑到精确班级/课次编号是本产品的显式查询条件，追加 `Vector-filtered` 和 `BM25-filtered` 稳健性对照。这是观察初步测试结果后的分析补充，不冒充原先预登记。原始向量、BM25、Latest 与消融结果全部保留。追加版本只按已给出的班级、课程、课次或作业及字段做相同元数据过滤，不读取金标、不改 k、不调向量权重。仍使用真实 BGE 相似度和 BM25 排序及同一批模型题。
3. 自动原文条件的主实验采用保守、确定性的原文语法路径 `generation/source-records.mjs`。不认识的文体会转给模型或待确认，绝不把人工 supersedes 注入自动解析。规模语料有规则生成文体，全部恰能被该语法解析，因此自动/人工同分不证明任意教师原文也能达到同分。另保存真实 Qwen 整理新课程多事项、含糊要求和截断失败的逐次原始输出。
4. 开发与测试按完整事件世界、课程和教学班隔离，词组族分开；未训练或微调模型。所有世界仍来自相同有限场景脚本，不能据此声称跨自然语言分布泛化。组长需要独立复核金标，尤其是随机问题抽查与非模板通知。
5. 唯一问句审计发现原 200 问/世界用了不足 200 个问法，出现重复文本。保留原冻结数据、结果及逐字不变的 200 道模型题，另在 `full/` 冻结去重完整实验：每种子 1,470 通知、13,000 唯一问题（测试 11,000），包括学校公告；原 200 题与单独冻结的 30 道公告题合计 230 题。去重只补问法，不新增性能调参，不以重复问法冒充事件覆盖；每种子测试仅有 1,100 个独立事件检查点，报告中显式列出。补充冻结发生在初版结果可见后，因此本轮属于开发实验，不能冒充组长尚未触碰的独立盲测。
