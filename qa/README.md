# 证据融合与回答

建议负责人为 **成员 B**。在[模块任务列表](https://github.com/666Dean/NowPast-RAG/issues)按 `[qa]` 找到任务并认领。

## 现有实现

已有规则合成、研究直查、旧线索回查与冲突状态。 本目录的主要文件为 answer.mjs。

## 职责与依赖

把时间快照、检索命中和研究来源组织成带引用的回答。

公共入口 answer(docs,question,{date,scope,mode,history})；向 web/service 提供 status、sections、items、research 与摘要。每条课程结论携带条款 ID。

## 第一项工作

审查两日期对比时的证据角色，以及一问多事项时的部分未知。用 B 组融合要求和设备费用各问一次，再组合成同一问题。

## 完成条件

有依据的事项可回答，未知事项单独标记；冲突并列，未签发的澄清不能泄露；研究原始依据与虚构课内通知标识清楚。

提交时写明所改文件、用于验证的查询及实际结果。涉及其他模块的输入输出变更时，在 PR 中写出影响的调用方。[协作总表](../CONTRIBUTING.md)
