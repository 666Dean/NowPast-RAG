## 现有实现

现有服务默认监听 127.0.0.1:4173。公开 GitHub 地址可浏览源码，比赛站点仍待部署。 本目录的主要文件为 server.mjs。

## 职责与依赖

维护网页资源入口、模型接口和运行环境边界。

上接 web 的 JSON 请求，调用 qa 重算证据，调用 generation 生成。资源映射须覆盖所有前端 ES 模块。

## 第一项工作

从全新克隆启动，验证静态模块加载、模型缺失、资料不足、有效推理的响应。后续取得实际平台条件后再单独设计部署适配，并登记真实 Qoder 贡献。

## 完成条件

Node 22+ 可启动；研究直查和证据不足的模型请求返回 422，模型不可用返回 503；公网验收须有实际匿名访问记录。

提交时写明所改文件、用于验证的查询及实际结果。涉及其他模块的输入输出变更时，在 PR 中写出影响的调用方。[协作总表](../CONTRIBUTING.md)
