# 校务通知工作台

在仓库根目录执行 `npm start`，打开 http://127.0.0.1:4173/。现有暖白、暗红布局与交互保留。

当前页面只使用 `knowledge/notices.mjs` 中的学校公告、教师课程安排和作业示例。原 GNP 资料仍用于独立引擎回归，不进入主界面的通知列表。首页与通知中心直接显示时间、地点、事项；原通知显示具体标题和公布日期，可打开原文。生效日期不作为上课时间，缺少依据的字段保留待确认。

教师只填写标题、完整原文、公布日期和接收范围；TXT 文件也可读取。`POST /api/notices/analyze` 调用真实本地 Qwen 选取原文要求，再检索和比较同课程、同主题、范围相交且已公布的旧通知。核验原文值、引文、日期和关联后，整体保存到浏览器。处理失败保留输入，关闭发布窗口会取消本次浏览器保存。主页面隐藏 AI 比较、归类与算法解释。

`web/notice-relations.mjs` 提供原通知链接和当前时间、地点、事项的组合。一次教室变更继承同一课次的原上课时间，作业延期保留原提交地点和作业要求。首页、通知、日程与课程空间共用这些结果。当前安排按同一课次或作业去重，全部版本及通知原文仍可查看。

首页置顶通知、通知列表与原文抽屉以浅暖棕色删除线显示明确被替代的旧值，紧随当前值；只比较直接前一版本中发生变化的字段，并保留日期和事项语境。并行、冲突、沿用及缺少生效依据的要求不会标成已替代。卡片悬停、按下和键盘聚焦时，旧值提供轻微颜色反馈；窄屏自动换行，减少动态效果时即时切换。原通知标题仍可点击核查完整内容。

角色切换是展示视角；原型尚无真实身份认证、多用户分发或学校系统接入。当前所有学校、教师及班级材料均为自编示例，该说明收在帮助中。

## 验证

`npm test` 运行原有引擎回归与新增通知核验。`node service/verify-delivery.mjs` 从源码副本运行冻结评测、开发回归及 HTTP；准备好模型缓存后设置 `NOWPAST_MODEL_HOME` 并追加 `--model`，会真实调用课程与作业通知分析接口。指定提交可追加 `--ref <commit>`。

新增测试包括原文与日期核验、关联对象、已公布范围、班级隔离、同课次时间继承、作业延期和缺证状态。浏览器验证覆盖教师原文发布、具体旧通知打开、刷新、历史日期、班级切换与移动布局。
