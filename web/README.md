## 现有实现

已有问答、来源查看、组别/日期筛选、TXT 导入、多条替代和来源链接。 本目录的主要文件为 index.html、app.mjs、style.css。

## 职责与依赖

交付从提问到结论、原文、加入新条款、重新查询的操作闭环。

使用知识层 schema 和 qa 的 answer；可选 POST /api/generate。自定义资料存在当前浏览器的 localStorage。
