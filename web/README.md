# 课程工作台与证据问答

执行负责人为 **Codex**。[Issue #7](https://github.com/666Dean/NowPast-RAG/issues/7) · [协作总表](../CONTRIBUTING.md)

## 启动

在仓库根目录运行 npm start，打开 http://127.0.0.1:4173/。无需新增 npm 依赖，使用 Node.js 22+。

## 页面

- 首页：重点通知、当前组别通知、周历、下一项安排、验收地点与准备清单。
- 课程空间：按日期、组别整理的当前课程要求。
- 通知中心：未读、变更、收藏、关键词与版本状态筛选；支持全部已读和撤销。
- 课程安排：周历与方向键选择；仅使用条款明确给出的日期与截止时间。验收时间未知时显示待定。
- 证据问答：保留日期、组别、版本对比、引用、论文与固定源码出处，以及可选模型整理。
- 课程资料：原始条款、UTF-8 TXT 导入、明确替代与刷新后检索。
- 帮助：演示资料、角色视角、浏览器存储、模型调用与交互说明。

学生和教师只是展示视角。教师有新增通知入口；资料、收藏、已读和清单存于当前浏览器，不会自动发送给其他用户。

## 视觉与动画

按用户最新参考图采用顶部导航、暖白与暗红、半透明面板和晨光雪山横幅。雪山为单独的 WebP 素材（约 76 KB），页面文字和按钮仍为 HTML。生成来源和完整提示词在 assets/mountain-dawn.webp.json；完整设计 tokens 与组件在根目录 DESIGN.md、.impeccable/design.json。

交互动画按操作区分：导航与日历滑动底板，筛选列表短距离过渡，收藏描边/填充，清单绘制勾选，搜索遮罩展开，原文抽屉横向进出，导入面板纵向淡入淡出，保存与整理显示忙碌状态。常规按钮只保留轻微按压反馈。

角色、组别、通知状态、查询方式及导入范围使用与页面一致的自定义下拉浮层，日期有配套月历，主题建议也使用同样材质。菜单具有展开、收合、选项跟随和选定值交接动画。中途收合从当前画面继续，快速反复操作不会留下重复菜单。支持键盘选择、取消、焦点恢复和减少动态效果。

900px 以下调整真实 DOM 顺序，确保视觉顺序与键盘顺序一致；700px 以下使用底部导航。按 / 或 Ctrl / ⌘ + K 展开搜索，Esc 关闭搜索或当前原文/导入面板。

## 接口与文件

主要入口为 index.html、style.css、app.mjs；controls.mjs 与 controls.css 封装选择器、月历、主题建议和语义动效。沿用 knowledge 的 schema、temporal 的 snapshot 和 qa 的 answer。可选 POST /api/generate 接口不变。service/server.mjs 增加前端模块、样式和图片的静态资源白名单项。
