如何查看课程要求？

选择日期和班级，即可查看当时已公布的通知。进入通知问答，可核查当前要求、待生效条款、历史版本和材料冲突。点击通知或引用可阅读原文。

这里的课程资料来自哪里？

当前学校公告、课程安排和作业均为本项目自编示例，不代表真实学校发布。只有通知原文明示的时间、地点和事项才会展示；未公布的信息保留待确认。

学生和教师视角有什么不同？

视角切换调整教学与学习操作的入口，不代表真实身份认证或权限切换。新增资料、已读、收藏和准备清单仅保存于当前浏览器，不会向学生或老师发送消息。

导入与模型整理如何工作？

教师填写通知标题和完整原文，服务自动整理要求并比对旧通知。关联通知以具体标题显示，可打开原文。模型不可用时保留输入。发布、已读和收藏存储在当前浏览器，本原型尚未连接学校发布系统。

界面与交互参考

布局、暖白与暗红配色来自用户提供的最新参考图。按钮、导航、收藏、日历与清单使用对应的交互动画，节奏参考 Bencho，由本项目原生 JavaScript 与 CSS 实现。按 / 或 Ctrl / ⌘ + K 可展开搜索，Esc 关闭原文面板。
