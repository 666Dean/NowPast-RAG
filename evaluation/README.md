# 独立评测与验收

执行负责人为 **Codex**。任务跟踪见 [Issue #9 · 独立评测与验收](https://github.com/666Dean/NowPast-RAG/issues/9)。

## 现有实现

交接基线有 38 道当前依据题、4 道来源定位题及 22 项行为检查。 本目录的主要文件为 cases.mjs、run.mjs、REPORT.md、results.json。

## 职责与依赖

维护金标、消融、边界回归和逐题失败分析。

直接使用 knowledge、retrieval 和 qa 的入口；npm run eval 会重写本目录报告和逐题 JSON。

## 第一项工作

先复跑冻结基线，再由未编写检索实现的成员独立写一组改写与跨版本问题，预先封存预期证据；复核 GNP08/X06/X07，记录新老题结果并分表。

## 完成条件

报告列出样本分母、证据预算、组别/时间条件、精确集合/F1 和失败项。把修复过的回归题与新题分开。

提交时写明所改文件、用于验证的查询及实际结果。涉及其他模块的输入输出变更时，在 PR 中写出影响的调用方。[协作总表](../CONTRIBUTING.md)
